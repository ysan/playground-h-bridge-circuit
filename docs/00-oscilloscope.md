# 00. オシロスコープ (RIGOL DS1102Z-E)

波形の確認に使っているオシロスコープの、使い方のメモです。各テーマの記録 (02 の 7 章など) では、ここに書いた方法で画面や波形のデータを取り込んでいます。

## 1. 使っているオシロ

| 項目 | 内容 |
|---|---|
| 型番 | RIGOL DS1102Z-E (DS1000Z 系、2チャンネル) |
| ファームウェア | 00.06.04 (`*IDN?` の返事で確認) |
| 画面 | 800 × 480、目盛りは横 12マス × 縦 8マス |

前面にプリンタの絵のボタン (Quick / Print) があるのが、DS1000Z 系の目印です。古い DS1102E とは、メニューが少し違います。

## 2. 画面の保存

### USB メモリに保存する

前面の USB 端子に USB メモリを挿し、プリンタの絵のボタンを押すか、**Storage** → 種類を **Picture** (PNG) → **Save** で保存します。

USB メモリによっては、挿したときにオシロが固まることがあります (電源を入れ直すしかない)。FAT32 でフォーマットした、容量の小さいものが無難です。

### LAN で PC に取り込む (おすすめ)

USB メモリを抜き差しせずに、PC から画面を PNG で取り込めます。

1. オシロの背面の LAN 端子を、ルーターにつなぐ
2. **Utility** → **IO Setting** → **LAN Conf.** で IP アドレスを設定する (このリポジトリでは `192.168.50.220`)
3. PC から、取り込みのスクリプトを実行する

```sh
python3 tools/scope_capture.py docs/images/02/1-3-h-pulse.png
python3 tools/scope_capture.py out.png --host 192.168.50.220   # IP アドレスを指定する場合
```

IP アドレスは、`--host` か、環境変数 `SCOPE_HOST` で指定します (どちらもなければ `192.168.50.220`)。

オシロは、測定器の共通のコマンド (SCPI) を、TCP の 5555 番で受け付けます。つながるかどうかは、機器の名前を問い合わせる `*IDN?` で確かめられます。

```sh
python3 -c 'import socket; s=socket.create_connection(("192.168.50.220",5555),3); s.sendall(b"*IDN?\n"); print(s.recv(256).decode())'
# RIGOL TECHNOLOGIES,DS1102Z-E,...,00.06.04
```

メニューの名前は、ファームウェアによって少し違うことがあります。

## 3. 測定値とカーソル

### 測定値 (Measure)

**Measure** ボタンを押すと、画面の左に測定の種類 (Period、Freq、+Width など) が並びます。右のメニューの **Source** でチャンネルを選び、左のアイコンを押すと、画面の下に測定値が並びます (最大 5 つ)。

| 確認したいこと | 測定の種類 |
|---|---|
| パルスの幅 | +Width |
| 周波数、デューティ | Freq、+Duty |
| High と Low の電圧 | Vtop、Vbase (とげを含む最大値は Vmax) |
| 立ち上がり、立ち下がりの速さ | Rise Time、Fall Time |

### カーソル (Cursor)

**Cursor** → **Mode** を **Manual** にし、**Select** で時間 (X) を選ぶと、縦の線を2本動かして、時間の差 (ΔX) を測れます。**Auto** にすると、選んだ測定に合わせてカーソルが自動で表示されます。

時間 (X) を選んでいても、電圧 (Y) の線と値も一緒に表示されるようです。気になるときは、Y の線を、画面の上の端と下の端に動かしておきます。

## 4. 自動測定がうまくいかないとき: 波形のデータから計算する

切り替わりの瞬間に細いとげがあると、オシロの自動測定 (+Width など) が、とげを別のパルスとして数えて、エラーになることがあります ([02 の動作確認](02-half-bridge-test.md) の 1-3)。

そのときは、オシロのメモリにある波形のデータを PC に取り込んで計算します。

1. オシロを STOP にして、波形を止める
2. SCPI のコマンドで、チャンネルごとにデータを取り込む

   | コマンド | 意味 |
   |---|---|
   | `:WAV:SOUR CHAN1` | 取り込むチャンネル |
   | `:WAV:MODE RAW` | メモリの全部 (画面の1200点ではなく、最大で数百万点) |
   | `:WAV:FORM BYTE` | 1点を1バイトで受け取る |
   | `:WAV:PRE?` | 時間の間隔と、電圧への換算の係数 |
   | `:WAV:STAR n`、`:WAV:STOP m`、`:WAV:DATA?` | n 番目から m 番目の点を受け取る (1回に 25万点まで) |

3. しきい値 (例: 6V) を超えている区間を探し、短すぎる区間 (例: 1ms 未満) をとげとして無視して、パルスの幅や間隔を計算する

例えば、`s` の静的テストを 1s/div で取り込むと、600万点 (2µs ごと) のデータになり、5ms や 10ms のパルスの幅を、2µs の細かさで計算できます。

## 5. プローブ

- プローブは 10:1 にして、オシロの側のチャンネルの設定も 10:1 に合わせる
  - プローブの側: 持ち手の 1X / 10X の切り替えスイッチを 10X にする
  - オシロの側: 前面の **CH1** (または **CH2**) ボタン → 右のメニューの **Probe** を **10X** にする
  - 両方がそろっていないと、表示の電圧が 10倍または 1/10 になる。1X どうしでも電圧は正しく表示されるが、帯域が数 MHz 程度に下がり、測る回路への影響も大きくなるので、デッドタイムや切り替わりのとげのような速い変化は 10X で見る
- GND クリップは、測る場所の近くの GND につなぐ。線が長いと、切り替わりの瞬間にとげが出やすい
- GND クリップは、オシロ本体を通してアースにつながっている。GND でない場所 (ハーフブリッジの中点など) につなぐと、そこが GND に短絡する ([02 の動作確認](02-half-bridge-test.md) の 3 節)
