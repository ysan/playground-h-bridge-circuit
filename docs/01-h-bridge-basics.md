# 01. Hブリッジの基礎

## Hブリッジとは

4つのスイッチ (Q1〜Q4) をHの字に並べ、中央の横棒の位置にモーターをつないだ回路です。
どのスイッチをONにするかで、モーターにかかる電圧の極性を切り替えられます。

```
        Vm
   +-----+-----+
   |           |
  Q1 (高側)   Q3 (高側)
   |           |
   +---[ M ]---+
   |           |
  Q2 (低側)   Q4 (低側)
   |           |
   +-----+-----+
        GND
```

(Q1/Q2 が左のハーフブリッジ、Q3/Q4 が右のハーフブリッジです。)

## 動作状態

| Q1 | Q2 | Q3 | Q4 | モーターの状態 |
|----|----|----|----|----------------|
| ON | OFF | OFF | ON | 正転 (左 → 右へ電流) |
| OFF | ON | ON | OFF | 逆転 (右 → 左へ電流) |
| OFF | ON | OFF | ON | ブレーキ (両端をGNDへ短絡) |
| ON | OFF | ON | OFF | ブレーキ (両端をVmへ短絡) |
| OFF | OFF | OFF | OFF | フリー (惰性回転) |
| ON | ON | - | - | **禁止**: 左側で電源が短絡 (シュートスルー) |
| - | - | ON | ON | **禁止**: 右側で電源が短絡 (シュートスルー) |

## 設計上の要点

### シュートスルー (貫通電流)

同じハーフブリッジの上下スイッチが同時にONになると、電源とGNDが直接つながり大電流が流れて素子が壊れます。
スイッチング時には、片方をOFFにしてから少し待って (デッドタイム)、もう片方をONにする必要があります。
ファームウェアでの対策だけでなく、リセット中やピンが不定の間にも短絡しない回路構成にすることが重要です。

### 逆起電力と還流ダイオード

モーターはインダクタンスを持つため、スイッチをOFFにしても電流が急には止まらず、
電流を流し続けようとして電圧が発生します。この電流の逃げ道として、
各スイッチに並列に還流ダイオードが必要です。MOSFETでは内蔵のボディダイオードがその役割をしますが、
BJTでは外付けします。

### 高側スイッチの駆動

高側にNch MOSFETを使う場合、ONにするにはソース電位 (= モーター端子電圧) よりゲート電圧を
10V程度高くする必要があります。このため、ブートストラップ回路やチャージポンプ付きのゲートドライバが使われます。
高側にPch MOSFETを使えば駆動は簡単ですが、同じ性能ではNchのほうがオン抵抗が低く有利です。

## PWM駆動の方式

速度は、電圧を高速にON/OFFして平均電圧を変えることで制御します。

- **Sign-Magnitude**: 一方の向きの低側 (または高側) だけをPWMし、反対側は常時ON。
- **Lock-Antiphase**: 対角のペアを交互に切り替える。デューティ50%で停止し、実装は簡単ですが電流リップルが大きい。

各方式は、後続のテーマでMCUのタイマ (TCA0) を使って実際に試し、波形を比較します。
