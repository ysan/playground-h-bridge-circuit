# 02. ハーフブリッジ (IRS2003 + 2SK4017)

Hブリッジの半分 (上下2個のMOSFET) を、ゲートドライバIC IRS2003S で駆動します。
まず抵抗負荷でスイッチングの波形を確認し、次の 03 でHブリッジ (ハーフブリッジ2組) にします。

## 2. IRS2003 のデータシートから確認した事項

出典: [Infineon IRS2003 データシート (PD60269)](https://www.infineon.com/assets/row/public/documents/24/49/infineon-irs2003-datasheet-en.pdf)

### ピン配置 (SOIC-8)

上から見た図で、左上の `*` が1番ピンです。

```
              IRS2003S
          +-----\_/-----+
 VCC    1 |*           | 8   VB
 HIN    2 |            | 7   HO
 /LIN   3 |            | 6   VS
 COM    4 |            | 5   LO
          +-------------+
```

| ピン | 名前 | 機能 |
|---|---|---|
| 1 | VCC | 低側とロジックの電源 (10〜20V) |
| 2 | HIN | 高側入力。**正論理** (1 で HO がON) |
| 3 | /LIN | 低側入力。**負論理** (0 で LO がON) |
| 4 | COM | 低側のリターン (GND) |
| 5 | LO | 低側ゲート出力 |
| 6 | VS | 高側のフローティング電源のリターン (= ハーフブリッジの中点) |
| 7 | HO | 高側ゲート出力 |
| 8 | VB | 高側のフローティング電源 |

### 主な電気的特性

| 項目 | 値 |
|---|---|
| ゲート駆動電源 VCC | 10〜20V |
| VCC低電圧保護 (UVLO) | 立ち上がり 8.9V (8〜9.8V)、立ち下がり 8.2V (7.4〜9V) |
| 入力しきい値 | VIH 2.5V以上、VIL 0.8V以下 (3.3V・5Vロジックで使える) |
| 出力電流 | ソース 130mA以上、シンク 270mA以上 (パルス) |
| ターンオン遅延 / ターンオフ遅延 | 標準 680ns / 150ns |
| 内蔵デッドタイム | 標準 520ns (400〜650ns) |
| 高側オフセット電圧 | 最大 200V |

### 入力の動作

- /LIN は反転入力です。**HIN と /LIN に同じ信号を入れると、HO と LO は逆になります (相補駆動)。**
- 待機状態 (上下ともOFF) は **HIN=0、/LIN=1** です。
- HIN と /LIN を同時に有効にしても、上下が同時にONにならないよう、貫通防止ロジックが働きます (データシート図1)。ただし、これに頼らず、ファームウェアでも同時ONにしないようにします。
- UVLO は VCC についてだけ記載があり、**VBS (ブートストラップ側) の低電圧保護はデータシートに載っていません。** ブートストラップコンデンサが放電したままHOを使うと、ゲート電圧が不足したまま動く可能性があります (第4節)。
- Infineon は IRS2003 を新規設計に推奨していません (後継: IRS2007)。

## 3. 回路の構成

ロジック部 (ATtiny1604 と IRS2003S):

```
 ATtiny1604                                         IRS2003S

 +5V (1番, VCC) ──┐
                  [10kΩ]  プルアップ
                  │
 PA5 (3番) ───────┴──────────────────────────────  /LIN (3番)

 PA4 (2番) ───────┬──────────────────────────────  HIN  (2番)
                  [10kΩ]  プルダウン
                  │
 GND (14番) ──────┴──────────────────────────────  COM  (4番)

                       +12V ───────────────────────  VCC  (1番)
                                  (C_vcc を VCC と GND の間に入れる)
```

- ATtiny1604 の電源 (1番ピン) は、FT232RQ モジュールの 5V です。IRS2003 の VCC は +12V です。**電圧が違うので、混ぜないこと。**
- **GND は、ATtiny1604、IRS2003 (COM)、電源、FT232RQ のすべてを共通にします。**
- PA4 は HIN に、PA5 は /LIN につなぎます。5V の信号は、IRS2003 の入力しきい値 (VIH 2.5V 以上) を十分に超えます。
- プルダウンとプルアップは、ATtiny1604 のリセット中や書き込み中にピンが浮いても、上下ともOFFの状態 (HIN=0、/LIN=1) を保つためのものです。

電源部 (MOSFET と負荷):

```
 +12V ─────┬──────────────┐
           │              │
        C_bus            D (ドレイン)
           │      HO ─Rg_H─ G   Q_H
           │              S (ソース)
           │              │
           │              ├───────── VS (pin6) ──── 負荷 ──── GND
           │              │
           │              D (ドレイン)
           │      LO ─Rg_L─ G   Q_L
           │              S (ソース)
           │              │
 GND ──────┴──────────────┘
```

ブートストラップ部 (高側のゲート電源):

```
 +12V ──── D_boot ────┬──── VB (pin8)
          (A → K)     │
                    C_boot
                      │
                      └──── VS (pin6)
```

### なぜ高側に特別な仕組みが必要か

Nch MOSFET をONにするには、**ゲート電圧がソース電圧より 10V 前後高い**必要があります。

- 低側のソースは GND (0V) に固定されているので、ゲートに 12V を加えればONになります。
- 高側のソースは、ONになるとモーター側 (VS) の電位になり、ほぼ 12V まで上がります。そのためゲートは、GND から見て約 22V 以上が必要です。

電源は 12V しかないので、高側には、コンデンサで電圧を持ち上げる**ブートストラップ**を使います。

### 低側の駆動 (ブートストラップなし)

```
 +12V ── VCC (pin1)
                       (ICの内部のスイッチ)
                    LO (pin5) ─Rg_L─ G   Q_L
                                     S ── GND
 GND ── COM (pin4) ───────────────────┘
```

- LO が High のとき、ゲートは VCC (12V) につながります。ソースは 0V なので、ゲート−ソース間は 12V でONになります。
- LO が Low のとき、ゲートは COM (GND) につながり、0V でOFFになります。

### 高側の駆動 (ブートストラップ)

2つの状態を繰り返します。

**① 低側がONのとき (充電)**

```
 +12V
  │
  ▼  D_boot   (電流が流れる向き)
  │
  ● VB = 11.5V
  │
 ─┴─ C_boot   (ここに電荷が溜まる)
 ─┬─
  │
  ● VS = 0V    ← 低側MOSFETがONで、GNDにつながっている
  │
 GND
```

コンデンサの両端の電圧は 11.5V − 0V = 11.5V です。この電圧が C_boot に溜まります (D_boot の順方向電圧分だけ、12V より低くなります)。

**② 高側がONのとき (使用)**

```
 +12V
  │
  ✕  D_boot   (逆向きの電圧がかかるので、電流が流れない)
  │
  ● VB = 23.5V  ← 11.5V + 12V
  │
 ─┴─ C_boot   (両端の電圧 11.5V が、そのまま保たれる)
 ─┬─
  │
  ● VS = 12V    ← 高側MOSFETがONで、+12Vにつながっている
  │
 +12V (高側MOSFETを通して)
```

- コンデンサは両端の電圧を保とうとするので、①で溜めた 11.5V は、②でもそのままです。
- ②では、コンデンサの下側 (VS) が 0V から 12V に持ち上がり、上側 (VB) も一緒に持ち上がって、12V + 11.5V = 23.5V になります。
- VB が電源の +12V より高くなるため、D_boot がないと電流が +12V へ逆流して、溜めた電荷が失われます。D_boot がこれを止めます。
- 高側のゲートは、VB と VS を電源として駆動されます。VB−VS は約 11.5V なので、高側MOSFETのゲート−ソース間に 11.5V がかかり、ONが保たれます。

C_boot は、VS と一緒に上下に動く、浮いた電池のように働きます。

### 低側と高側の比較

| 項目 | 低側 | 高側 |
|---|---|---|
| ゲート駆動電源 | VCC (12V、固定) | VB (C_boot で作る、浮いた電源) |
| 基準になるピン | COM (GND、動かない) | VS (中点、0V と 12V の間を動く) |
| ソースの電位 | 常に 0V | ONのとき約 12V まで上がる |
| 必要なゲート電圧 (GND基準) | 約 12V | 約 23.5V |
| 補助部品 | 不要 | D_boot と C_boot |

低側のONは、自分を駆動するだけでなく、高側のための C_boot を充電する役目も持っています。

### 配線例 (段階 1: MOSFET なし)

IRS2003 を上、ATtiny1604 を下に並べた配線の例です。ピン番号を図中に書いています。ATtiny1604 は、1〜7番ピンの側 (PA4、PA5) を使います。

```
           GND
            |                                   IRS2003S
          [10k]                             +------\_/------+
            |                    +12V ------| 1 VCC    VB 8 |--- D_boot K, C_boot +
  +---------*-------------------------------| 2 HIN    HO 7 |--- HO
  |  +---------------------------*----------| 3 /LIN   VS 6 |--- VS
  |  |                           |   GND ---| 4 COM    LO 5 |--- LO
  |  |                         [10k]        +---------------+
  |  |                           |
  |  |            ATtiny1604    +5V
  |  |        +-------\_/-------+
  |  |  +5V --| 1 VCC    GND 14 |
  +--|--------| 2 PA4    PA3 13 |
     +--------| 3 PA5    PA2 12 |
              | 4 PA6    PA1 11 |
              | 5 PA7    PA0 10 |
              | 6 PB3    PB0  9 |
              | 7 PB2    PB1  8 |
              +-----------------+
```

- 図の左の `[10k]`: HIN の線に付く10kΩは、GND へつなぐ (プルダウン)。/LIN の線に付く10kΩは、+5V へつなぐ (プルアップ)
- **線が交差していても `*` がなければ、接続していません。** (例: PA4 の横線と PA5 の縦線が交差する箇所)
- PA4 (2番) が HIN (2番)、PA5 (3番) が /LIN (3番) につながる
- IRS2003 の VCC (1番): +12V。VCC と GND の間に C_vcc (10µF と 0.1µF) を入れる
- IRS2003 の VB (8番): D_boot のカソード (K、帯のある側) と、C_boot (1µF) の片側。D_boot のアノードは +12V につなぐ
- IRS2003 の VS (6番): 段階 1 では GND。C_boot のもう一方もここにつなぐ
- IRS2003 の COM (4番): GND
- HO (7番) と LO (5番): オシロで観察する (何もつながない)
- ATtiny の +5V は FT232RQ モジュールの VCC、GND は全て共通にする
- ATtiny の GND (14番) と PA0 (10番、UPDI 用) は、図では省略しています。GND は全て共通にします

### 配線例 (段階 2 以降: MOSFET あり)

段階 1 の配線に、MOSFET (Q_H、Q_L) と負荷を加えた例です。ATtiny1604 側の配線は、段階 1 と同じです。

```
           GND
            |                                   IRS2003S                        +12V
          [10k]                             +------\_/------+               +-----+-----+
            |                    +12V ------| 1 VCC    VB 8 |-- (A)         | D         |
  +---------*-------------------------------| 2 HIN    HO 7 |-------[Rg_H]--| G   Q_H   |
  |  +---------------------------*----------| 3 /LIN   VS 6 |-------+       | S         |
  |  |                           |   GND ---| 4 COM    LO 5 |-+     |       +-----+-----+
  |  |                         [10k]        +---------------+ |     |             |
  |  |                           |                            |     *-------------*---- Load ---- GND
  |  |            ATtiny1604    +5V                           |                   |
  |  |        +-------\_/-------+                             |             +-----+-----+
  |  |  +5V --| 1 VCC    GND 14 |                             |             | D         |
  +--|--------| 2 PA4    PA3 13 |                             +-----[Rg_L]--| G   Q_L   |
     +--------| 3 PA5    PA2 12 |                                           | S         |
              | 4 PA6    PA1 11 |                                           +-----+-----+
              | 5 PA7    PA0 10 |                                                 |
              | 6 PB3    PB0  9 |                                                GND
              | 7 PB2    PB1  8 |
              +-----------------+
```

- `(A)`: D_boot のカソード (K、帯のある側) と、C_boot (1µF) の+側をつなぐ。D_boot のアノードは +12V。C_boot の−側は、IRS2003 の VS (6番) につなぐ
- Q_H (高側): ドレイン (D) が +12V、ソース (S) が中点
- Q_L (低側): ドレイン (D) が中点、ソース (S) が GND
- 中点は、IRS2003 の VS (6番) と、負荷の一端につなぐ。負荷のもう一端は GND
- `[Rg_H]`、`[Rg_L]`: ゲート抵抗 (22〜47Ω)。HO と LO から、それぞれ MOSFET のゲート (G) へ
- 段階 1 との違いは、**VS を GND ではなく、中点につなぐ**こと。MOSFET を載せたら、VS から GND への接続を外す
- 電源 (+12V) と GND の間の、MOSFET の近くに、C_bus を入れる (図では省略)

### 配線例 (全部入り)

段階 2 以降の配線に、ブートストラップ回路 (D_boot、C_boot)、コンデンサ (C_vcc、C_bus)、プルダウンとプルアップを描き足した例です。横に長い図なので、横にスクロールして見てください。

  |  |  +5V --| 1 VCC    GND 14 |                             |             | D         |

読み方:

- `*` は接続点です。**線が交差していても `*` がなければ、接続していません。** (例: HO の線と C_boot の縦線が交差する箇所、PA4 の横線と PA5 の縦線が交差する箇所)
- `+12V`、`GND`、`+5V` のラベルは、同じ名前のどうしが接続されている、という意味です (線では結んでいません)。
- `D_boot`: +12V から VB へ向かうダイオード (`v` が電流の向き、`-----` の帯が K = カソード)

- `C_bus`: +12V と GND の間。MOSFET のそばに置く
- 左の `[10k]`: HIN の線は GND へ (プルダウン)、/LIN の線は +5V へ (プルアップ)
- ATtiny の GND (14番) と PA0 (10番、UPDI 用) は、図では省略しています

### 部品値の考え方

- **ゲート抵抗 22Ω**: 2SK4017 の入力容量は 730pF 程度 (販売店の仕様値。要確認) と小さいため、数十Ω で十分です。ICのソース電流は 130mA 以上なので、立ち上がりは数百ns です。製作後に波形を見て調整します。
- **ブートストラップコンデンサ 1µF**: ゲート電荷量を仮に 20nC とすると、放電による電圧降下を 0.5V に抑えるには 40nF 以上が必要です。IC の VBS 消費電流 (最大 55µA) も加わるため、余裕を見て 1µF にします。耐圧 25V 以上のセラミック (X7R) を使います。(ゲート電荷量は未確認の仮定値です。)
- **ブートストラップダイオード**: SBM245L (45V) を使います。バス電圧は 12V なので耐圧は十分です。
- **プルダウン、プルアップ**: マイコンのリセット中や書き込み中はピンがハイインピーダンスになります。HIN を GND へ、/LIN をロジック電源へ引いておくと、そのときも上下ともOFFになります。
- **VCC=12V**: UVLO の上側しきい値 (標準 8.9V、最大 9.8V) を十分に超えます。VB は D_boot の順方向電圧分だけ低くなり、約 11.5V です。

## 4. ブートストラップの注意

C_boot は、**低側がONになって VS が GND に下がっている間**にだけ充電されます。

- 高側を100%連続でONにすると、C_boot が放電して高側がOFFになります。
- ファームウェアでは、デューティの上限を 90% にしています。
- 高側は、C_boot の電荷だけで駆動するため、IC 自身の消費電流 (最大 55µA) だけでも、1µF なら数百msで空になります。**高側を長時間ONにするテストはできません。**
- 起動直後は C_boot が空です。最初に低側を一度ONにしてから高側を使います (`main.c` の静的テストがこの順です)。
- IRS2003 には VB 側の低電圧保護がありません。C_boot が不足したまま HO を動かすと、ゲート電圧が足りず、MOSFET が半分だけONになって発熱するおそれがあります。

## 4.5 省略した部品 (ゲート−ソース間抵抗 R_gs)

学習用に部品を減らすため、MOSFET のゲートとソースの間に入れるプルダウン抵抗 (R_gs) を**省いています**。

R_gs は、ドライバが駆動していない間に、ゲートを0Vに保つための保護です。

- 電源を入れる途中や、ICが動いていないときに、ゲートが浮いて MOSFET が勝手にONになるのを防ぐ
- 隣の MOSFET の切り替えによるノイズで、ゲートが持ち上がるのを抑える

省いたことによる注意:

- **通電時は、電源の電流制限を低く (0.5A 程度) 設定したまま行う。** 万一、起動時に上下の MOSFET が同時にONになっても、電流制限で止まる。
- 発熱や異常な動作があれば、すぐに電源を切る。
- 基板化するときや、モーターのような大きな負荷をつなぐときは、入れることを勧める。値は、低側は 10kΩ 程度、高側は 100kΩ 程度にする (高側に小さい抵抗を入れると、C_boot の電荷を消費して、高側が長くONにできなくなる)。

## 5. ファームウェア

[`firmware/02-half-bridge/main.c`](../firmware/02-half-bridge/main.c)

| ピン | 機能 | 接続先 |
|---|---|---|
| PA4 (2番ピン、TCA0 WO4) | HIN | IRS2003 pin2 |
| PA5 (3番ピン、TCA0 WO5) | /LIN | IRS2003 pin3 |

PA4 と PA5 は、TCA0 の WO4 と WO5 の既定のピンです ([Microchip: TCA Pin Positions](https://onlinedocs.microchip.com/oxy/GUID-ACE76F82-8072-410B-AFA7-16B2BF7B4CBA-en-US-8/GUID-9E1155F0-F789-41FC-B240-9CAE98BBDC61.html))。WO3〜WO5 は TCA0 の分割モード (8bit×2) でのみ出力されるため、このファームウェアは分割モードを使います。実機ではオシロで波形を確認します。

動作は次の2段階です。

1. **静的テスト**: 全OFF (1秒) → 低側のみON (2秒) → 全OFF → 「低側5msON → 全OFF → 高側20msON」を20回 → 全OFF。高側は C_boot の電荷で駆動するため、長くONにできません。状態を切り替えるときは、必ず全OFFを挟みます。
2. **PWMテスト**: 約19.5kHz (8bit、256段階)、デューティを10%から90%まで10%刻みで往復 (各1秒)。HIN と /LIN に同じ波形を出して、相補駆動にします。デッドタイムは IC の内蔵分 (標準520ns) です。

ATtiny1604 の電源は、FT232RQ モジュールの 5V です。
クロックは 20MHz に設定しています (20MHz動作は電源 4.5V 以上が前提のため、3.3Vでは使えません。データシートで要確認) (既定は 20MHz/6 = 3.33MHz)。分割モードの TCA0 は8bitで、20MHz を4分周して周期256にすると、約19.5kHz になります。

```sh
docker exec avr-builder-dev make -C firmware/02-half-bridge flash PORT=/host-dev/ttyUSB0
```

## 6. 動作確認の手順

**必ずこの順に進めます。各段階で問題があれば、次に進みません。**

### 段階 0: 通電前

- [ ] 配線を接続表と照合する
- [ ] 電源のGNDと、ATtiny、FT232RQ のGNDが共通であること
- [ ] テスターで +12V と GND の間が短絡していないこと

### 段階 1: ロジックだけ確認 (MOSFET を実装しない)

- [ ] 電源を 12V、電流制限を 0.1A にする
- [ ] IRS2003 と ATtiny1604 だけをつなぐ。MOSFET、ゲート抵抗、負荷は未実装
- [ ] **VS (pin6) は GND につなぐ。** C_boot は、VS が GND に下がっている間にだけ充電されるため、こうしないと HO が動かない
- [ ] 消費電流が数mA以下であること
- [ ] オシロで HIN (pin2)、/LIN (pin3)、HO (pin7)、LO (pin5) を GND 基準で観察する。VS が GND なので、すべて GND 基準で測れる
- [ ] 静的テストで、次の順に変化すること

  | 時間 | 状態 | HIN | /LIN | HO | LO |
  |---|---|---|---|---|---|
  | 0〜1秒 | 全OFF | 0 | 1 | 0V | 0V |
  | 1〜3秒 | 低側のみON | 0 | 0 | 0V | 約12V |
  | 3〜4秒 | 全OFF | 0 | 1 | 0V | 0V |
  | 4〜6秒 | 低側5ms → 全OFF → 高側20ms を20回 | 20msだけ1 | 5msだけ0 | 20ms幅で約11.5V | 5ms幅で約12V |
  | 6〜7秒 | 全OFF | 0 | 1 | 0V | 0V |

- [ ] PWMテストで、HO と LO が逆相になり、切り替わりの間に両方0Vの時間 (デッドタイム、約520ns) があること

### 段階 2: MOSFET を実装、負荷なし

中点 (VS) は GND 基準でなくなる点に注意します。ゲート電圧 (HO−VS) を見るときは、プローブのGNDクリップを VS につなぐのではなく、2チャンネルで HO と VS を GND 基準で測り、オシロの演算機能で差を取ります。(オシロのプローブのGNDは、電源のGNDと共通になっています。)

- [ ] 電流制限を 0.5A にする
- [ ] 静的テストで、中点 (VS) が、LO のONで0V、HO のON (20ms幅のパルス) で12Vになること
- [ ] PWMテストで、中点の波形がデューティに応じて変化すること
- [ ] 中点のスイッチング波形、ゲートの立ち上がりと立ち下がり時間、デッドタイムを記録する (この docs に追記する)

### 段階 3: 抵抗負荷

- [ ] 負荷は 1A 以下 (12V のとき 12Ω 以上、消費電力 12W 以上の抵抗など)
- [ ] 電流制限を 1.5A 程度にする
- [ ] MOSFET の発熱を確認する (5分動かして、触れる程度であること)

ブレッドボードの接点は大電流向きではありません。**1A を超える場合は、ユニバーサル基板などに組み直します。**
