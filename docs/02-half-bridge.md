## 1. この章でやること

### 1.1 ハーフブリッジとは

上下に2個のスイッチ (MOSFET) を直列につなぎ、その間 (中点) から出力を取り出す回路です。上をONにすると中点は電源 (+12V) に、下をONにすると GND につながります。Hブリッジは、これを2組並べたものです ([01 Hブリッジの基礎](01-h-bridge-basics.md))。

この資料では、上側を**高側** (Q_H)、下側を**低側** (Q_L) と呼びます。

### 1.2 全体の構成

```
 ATtiny1604              IRS2003                 MOSFET
 (5V のロジック)         (ゲートドライバ)

   PA4 -----------------> HIN      HO --------> Q_H --+
                                                      +--> 中点 --> 負荷
   PA5 -----------------> /LIN     LO --------> Q_L --+
```

(Q_H が高側、Q_L が低側の MOSFET です。)

マイコンが「どちらをONにするか」を決め、ゲートドライバIC がその指示どおりに MOSFET のゲートを駆動します。

### 1.3 なぜゲートドライバICを使うか

マイコンのピンで、MOSFET のゲートを直接駆動しない理由は3つあります。

- **電圧に余裕がない**: マイコンのピンは 5V までです。2SK4017 は 4V でもONしますが、ゲートに 10V 前後をかけるとオン抵抗が下がり、発熱が減ります。
- **高側は、電源より高い電圧が要る**: 高側の MOSFET をONにするには、ゲートを +12V より高くする必要があります (3 節)。マイコンでは作れません。
- **切り替えを速く、安全にしたい**: IC は大きな電流でゲートを素早く充放電でき、上下が同時にONにならないためのデッドタイムも内蔵しています。

### 1.4 動かす予定のモーター

03 以降では、**12V の 370 サイズのギヤードモーター (エンコーダ付き)** を使う予定です (未購入)。

- **電圧**: 12V 用なので、このハーフブリッジのバス電圧 (12V) のまま使えます。
- **電流**: 無負荷で 0.1〜0.3A、ロックで 1〜3A 程度 (一般的な目安。製品の仕様で要確認) で、2SK4017 (5A) の範囲に収まります。
- **エンコーダ**: 05 の PID 制御で、回転数や角度を測るのに使います。モーター軸側 (ギヤの手前) に付いているものを想定しています。ギヤの遊び (バックラッシュ) は、速度制御ではほとんど影響しませんが、位置制御では出力軸の位置のずれになります。

540 や 775 のような大きなモーターは、電流が 2SK4017 とブレッドボードの限界を超えるため、この回路では扱いません。

### 1.5 この章のゴール

- 抵抗負荷をつないで、中点の電圧が、マイコンの指示どおりに 0V と 12V の間で切り替わることを、オシロで確認する
- ゲートの波形、デッドタイム、MOSFET の発熱を測って、7 章に記録する

## 3. ゲート駆動の仕組み

この節では、IRS2003 のピン名 (HO、LO、VB、VS など) を使います。ピンの一覧は 4.1 節にあります。

ブートストラップ回路は、いきなり出てくると理由がわかりにくい部品です。この節は、次の順に、理由をたどって説明します。

1. ブリッジでモーターを制御するには、MOSFET を「完全なON」と「完全なOFF」のスイッチとして使う (3.1)
2. 低側は、ゲートに 12V をかけるだけで完全にONにできる (3.2)
3. 高側は、ONにするとソースが持ち上がり、12V では完全にONにできない (3.3)
4. そこで、ソースより常に高い電圧を作るブートストラップ回路を使う (3.4)
5. ブートストラップのコンデンサは放電するので、スイッチングを続ける必要がある。ここからデューティの上限、周波数、コンデンサの容量が決まる (3.5)

### 3.1 MOSFET はスイッチとして使う

Hブリッジを使うのは、モーターの正転・逆転・ブレーキと、PWM による速度調整をするためです ([01 Hブリッジの基礎](01-h-bridge-basics.md))。どれも、MOSFET を**完全にON**にするか**完全にOFF**にするかの切り替えで実現します。速度も、ONとOFFを高速に繰り返す割合 (デューティ) で調整します。

中途半端な状態を避けるのは、発熱のためです。MOSFET の発熱は、ドレイン−ソース間の電圧と、流れる電流の積です。

| 状態 | ドレイン−ソース間の電圧 | 電流 | 発熱 (1A のとき) |
|---|---|---|---|
| 完全にON | ほぼ 0V (オン抵抗 0.1Ω × 1A = 0.1V) | 流れる | 約 0.1W |
| 完全にOFF | 12V | 0 | 0 |
| 中途半端なON | 数V | 流れる | 数W |

MOSFET を完全にONにするには、**ゲートとソースの間の電圧を十分に高くする**必要があります (2SK4017 は 4V 以上、10V 前後あれば十分)。ゲートの電圧は、GND から見た値ではなく、**ソースから見た値**で効きます。

### 3.2 低側は簡単: ソースが GND に固定されている

```
 +12V ── VCC (pin1)
                       (ICの内部のスイッチ)
                    LO (pin5) ─Rg_L─ G   Q_L
                                     S ── GND
 GND ── COM (pin4) ───────────────────┘
```

低側の MOSFET のソースは、GND (0V) に固定されています。ゲートに 12V をかければ、ゲート−ソース間も 12V で、完全にONになります。

- LO が High のとき、ゲートは VCC (12V) につながり、ONになります。
- LO が Low のとき、ゲートは COM (GND) につながり、0V でOFFになります。

### 3.3 高側の問題: ONにするとソースが持ち上がる

高側の MOSFET のソースは、中点 (VS) につながっています。仮に、高側のゲートに、低側と同じように GND から見て 12V をかけたとします。

| 時点 | 中点 (ソース) の電圧 | ゲート−ソース間の電圧 | MOSFET |
|---|---|---|---|
| ONにし始め | 0V | 12V − 0V = 12V | ONに向かう |
| 中点が上がる途中 | 6V | 12V − 6V = 6V | まだONに向かう |
| しきい値付近 | 9〜10V | 2〜3V | これ以上ONにならない |

MOSFET がONに向かうほど、中点 (ソース) が電源の 12V に近づき、ゲート−ソース間の電圧が減っていきます。ゲート−ソース間がしきい値 (2SK4017 で 1.3〜2.5V) 付近まで下がると、それ以上ONになれず、**中途半端なONのまま止まります**。

- 負荷には 12V ではなく、9〜10V 程度しかかかりません。
- MOSFET には数V の電圧と電流が同時にかかり、3.1 節の表の「中途半端なON」になって発熱します。

高側を完全にONにするには、**ゲートを、中点 (ソース) より常に 10V 前後高く保ち続ける**必要があります。中点が 12V まで上がるので、GND から見て約 22V 以上です。電源は 12V しかないので、このままでは作れません。

### 3.4 解決策: ブートストラップ回路

そこで、次の**ブートストラップ回路**で、中点より常に高い電圧を作ります。

```
 +12V ──── D_boot ────┬──── VB (pin8)
          (A → K)     │
                    C_boot
                      │
                      └──── VS (pin6)
```

- D_boot: +12V から VB へ向かう向きにだけ電流を流すダイオード (A がアノード、K がカソード)
- C_boot: VB と VS の間のコンデンサ。高側のゲートを駆動する電荷を溜める
- VS は中点につながっていて、0V と 12V の間を上下に動きます

考え方は、**中点の上に乗った電池**です。電池の下側が中点にくっついているので、中点が上がれば、電池の上側 (VB) も一緒に上がります。高側のゲートは、この電池 (VB と VS の間) で駆動するので、中点の電圧に関係なく、ゲート−ソース間に一定の電圧をかけられます。

この電池 (C_boot) は、2つの状態を繰り返して使います。

**① 低側がONのとき (充電)**

```
 +12V
  │
  ▼  D_boot   (電流が流れる向き)
  │
  ● VB = 11.5V
  │
 ─┴─ C_boot   (ここに電荷が溜まる)
 ─┬─
  │
  ● VS = 0V    ← 低側MOSFETがONで、GNDにつながっている
  │
 GND
```

低側がONなので、VS は 0V です。+12V から D_boot を通って電流が流れ、C_boot が約 11.5V に充電されます (D_boot の順方向電圧の分だけ、12V より低くなります)。

**② 高側がONのとき (使用)**

```
 +12V
  │
  ✕  D_boot   (逆向きの電圧がかかるので、電流が流れない)
  │
  ● VB = 23.5V  ← 11.5V + 12V
  │
 ─┴─ C_boot   (両端の電圧 11.5V が、そのまま保たれる)
 ─┬─
  │
  ● VS = 12V    ← 高側MOSFETがONで、+12Vにつながっている
  │
 +12V (高側MOSFETを通して)
```

- コンデンサは両端の電圧を保とうとするので、①で溜めた 11.5V は、②でもそのままです。
- ②では、コンデンサの下側 (VS) が 0V から 12V に持ち上がり、上側 (VB) も一緒に持ち上がって、12V + 11.5V = 23.5V になります。
- VB が電源の +12V より高くなるため、D_boot がないと電流が +12V へ逆流して、溜めた電荷が失われます。D_boot がこれを止めます。
- 高側のゲートは、VB と VS を電源として駆動されます。VB−VS は約 11.5V なので、高側MOSFETのゲート−ソース間に 11.5V がかかり、完全にONのまま保たれます。

### 3.5 代償: 放電するので、スイッチングを続ける

C_boot は、**低側がONになって VS が GND に下がっている間**にだけ充電されます。一方、高側がONの間は、次のものに電荷を取られて、電圧が下がり続けます。

- 高側のゲートを充電する電荷 (ONにするたび。仮に 20nC)
- IC 自身の消費電流 (最大 55µA)
- 高側のゲート−ソース間抵抗 R_gs_H (100kΩ で約 0.115mA。5.3 節)

このため、**高側をONにし続けることはできません。** 定期的に低側をONにして C_boot を充電し直す、つまり**高側と低側のスイッチングを続ける**必要があります。PWM でモーターを駆動するのは速度を変えるためですが、高側を使うためにも、スイッチングは欠かせません。

ここから、次の値が決まります。

**デューティの上限**: 1周期の中に、低側がONの時間 (充電の時間) を残す必要があります。このファームウェアでは上限を 90% にしています。約19.5kHz なら、1周期 約 51µs のうち、約 5µs が充電の時間です。

**周波数**: 周波数が低いほど、1回の高側ONの時間が長くなり、その間の電圧低下が大きくなります。デューティ 90%、C_boot = 1µF、ゲート電荷 20nC、消費電流と R_gs_H の電流の合計 約 0.17mA として計算すると、次のとおりです。

| PWM の周波数 | 1回の高側ONの時間 | 1回あたりの C_boot の電圧低下 |
|---|---|---|
| 約19.5kHz (このファームウェア) | 約 46µs | 約 0.03V |
| 1kHz | 約 0.9ms | 約 0.17V |
| 100Hz | 約 9ms | 約 1.6V |

周波数を下げすぎると、高側のゲート電圧が下がって、3.3 節の「中途半端なON」に近づきます。

**C_boot の容量**: 上の電圧低下が十分小さくなるように選びます。1µF にした理由は 5.3 節にあります。

そのほかの注意:

- **起動直後は C_boot が空です。** 最初に低側を一度ONにしてから、高側を使います。
- **C_boot が不足したときの保護がありません。** IRS2003 には VB 側の低電圧保護がないので、C_boot が不足したまま HO を動かすと、3.3 節と同じ中途半端なONになって発熱するおそれがあります。
- 動作確認の静的テストで、高側を 10ms だけONにしているのも、この放電のためです (6.1 節)。

### 3.6 低側と高側の比較

| 項目 | 低側 | 高側 |
|---|---|---|
| ゲート駆動電源 | VCC (12V、固定) | VB (C_boot で作る、浮いた電源) |
| 基準になるピン | COM (GND、動かない) | VS (中点、0V と 12V の間を動く) |
| ソースの電位 | 常に 0V | ONのとき約 12V まで上がる |
| ON時のゲート電圧 (GND基準) | 約 12V | 約 23.5V (必要なのは約 22V 以上) |
| 補助部品 | 不要 | D_boot と C_boot |
| 制約 | なし | 連続ONにできない。スイッチングを続ける |

低側のONは、自分を駆動するだけでなく、高側のための C_boot を充電する役目も持っています。

## 4. IRS2003 のデータシートから確認した事項

出典: [Infineon IRS2003 データシート (PD60269)](https://www.infineon.com/assets/row/public/documents/24/49/infineon-irs2003-datasheet-en.pdf)

### 4.1 ピン配置 (SOIC-8)

上から見た図で、左上の `*` が1番ピンです。

```
              IRS2003S
          +-----\_/-----+
 VCC    1 |*           | 8   VB
 HIN    2 |            | 7   HO
 /LIN   3 |            | 6   VS
 COM    4 |            | 5   LO
          +-------------+
```

| ピン | 名前 | 機能 |
|---|---|---|
| 1 | VCC | 低側とロジックの電源 (10〜20V) |
| 2 | HIN | 高側入力。**正論理** (1 で HO がON) |
| 3 | /LIN | 低側入力。**負論理** (0 で LO がON) |
| 4 | COM | 低側のリターン (GND) |
| 5 | LO | 低側ゲート出力 |
| 6 | VS | 高側のフローティング電源のリターン (= ハーフブリッジの中点) |
| 7 | HO | 高側ゲート出力 |
| 8 | VB | 高側のフローティング電源 (C_boot の+側) |

### 4.2 主な電気的特性

| 項目 | 値 |
|---|---|
| ゲート駆動電源 VCC | 10〜20V |
| VCC低電圧保護 (UVLO) | 立ち上がり 8.9V (8〜9.8V)、立ち下がり 8.2V (7.4〜9V) |
| 入力しきい値 | VIH 2.5V以上、VIL 0.8V以下 (3.3V・5Vロジックで使える) |
| 出力電流 | ソース 130mA以上、シンク 270mA以上 (パルス) |
| ターンオン遅延 / ターンオフ遅延 | 標準 680ns / 150ns |
| 内蔵デッドタイム | 標準 520ns (400〜650ns) |
| 高側オフセット電圧 | 最大 200V |

### 4.3 入力の動作

| HIN | /LIN | HO | LO | 状態 |
|---|---|---|---|---|
| 0 | 1 | OFF | OFF | 全OFF (待機状態) |
| 0 | 0 | OFF | ON | 低側のみON |
| 1 | 1 | ON | OFF | 高側のみON |
| 1 | 0 | — | — | 上下が同時にON の指示。IC の貫通防止ロジックが働く (使わない) |

- /LIN は反転入力です。**HIN と /LIN に同じ信号を入れると、HO と LO は必ず逆になります (相補駆動)。** 6 章の PWM は、この性質を使います。
- HO と LO が切り替わるとき、IC が自動でデッドタイム (両方OFFの時間、標準 520ns) を入れます。
- 上下が同時にONになる指示 (表の最後の行) でも、貫通防止ロジックが働きます (データシート図1)。ただし、これに頼らず、ファームウェアでもこの指示を出さないようにします。
- 低電圧保護 (UVLO) は VCC についてだけ記載があり、**VB 側の低電圧保護はデータシートに載っていません** (3.5 節)。
- Infineon は IRS2003 を新規設計に推奨していません (後継: IRS2007)。

## 5. 回路

### 5.1 構成

電源部 (MOSFET と負荷):

```
 +12V ---*--------------------------+
         |                          |
         |                          D
         |  HO--[Rg_H]---*--------G    Q_H
         |               |          S
         |       R_gs_H  |          |
         |               +-[100k]---*
        --- C_bus                   |
        ---                         *---- VS (6番ピン)、負荷へ
         |                          |
         |                          D
         |  LO--[Rg_L]---*--------G    Q_L
         |               |          S
         |       R_gs_L  |          |
         |               +-[10k]----*
         |                          |
 GND ----*--------------------------+
```

- Rg_H、Rg_L はゲート抵抗、R_gs_H、R_gs_L はゲートとソースの間の抵抗です (5.3 節)。
- ブートストラップ部 (D_boot、C_boot) は、3.4 節の図のとおりです。

電源とGND:

- ATtiny1604 の電源は、FT232RQ モジュールの 5V です。IRS2003 の VCC は +12V です。**+5V と +12V をつながないこと。**
- **GND は、ATtiny1604、IRS2003 (COM)、12V 電源のマイナス端子、FT232RQ のすべてを共通にします。** プラス側は 5V と 12V の2系統ですが、GND は1つです。GND が共通でないと、ATtiny1604 が出す信号 (PA4、PA5) の基準と、IRS2003 が受け取る基準がずれて、HIN と /LIN を正しく判定できません。
- ATtiny1604 の PA4 を HIN に、PA5 を /LIN につなぎます。5V の信号は、IRS2003 の入力しきい値 (VIH 2.5V 以上) を十分に超えます。

GND は1点でつなぎます:

```
 12V 電源の -  ---*---- Q_L のソース、C_bus の -        (電力の GND: 太く短く)
                  |
                  +---- IRS2003 の COM                    (Q_L のソースの近く)
                  |
                  +---- ATtiny1604 の GND、FT232RQ の GND (ロジックの GND: 1本の線で)
```

- 12V 電源のマイナス端子からの線、Q_L のソース、C_bus の − を、1か所に集めます。そこが GND の中心 (`*`) です。
- 負荷の電流は、Q_L のソースから、電源のマイナス端子へ、太く短い線で戻します。
- IRS2003 の COM は、中心 (= Q_L のソースのそば) に短い線でつなぎます。LO がゲートを駆動する電流は、COM と Q_L のソースの間を回るためです。
- ATtiny1604 と FT232RQ の GND は、中心から1本の線でつなぎ、負荷の電流がこの線を通らないようにします。

負荷の電流が、ATtiny1604 の GND の線や USB ケーブルを通って電源へ戻ると、その線の抵抗で電圧が生じます。すると、ATtiny1604 から見た GND が揺れて、信号の判定や書き込みが不安定になります。1点でつなぐのは、これを避けるためです。

図は概略です。**接続は、次の接続表を正とします。** (KiCad の回路図は `hardware/` に追加予定です。)

### 5.3 部品値の考え方

**ゲート抵抗 Rg_H、Rg_L (22〜47Ω)**

2SK4017 の入力容量は 730pF 程度 (販売店の仕様値。要確認) と小さいため、数十Ω で十分です。IC のソース電流は 130mA 以上なので、立ち上がりは数百ns です。抵抗の主な役目は、ゲート配線の振動 (リンギング) を抑えることです。配線の長いブレッドボードでは 47Ω から始め、波形を見て下げます。

**ゲート−ソース間抵抗 R_gs_H (100kΩ)、R_gs_L (10kΩ)**

ドライバが駆動していない間に、ゲートを0Vに保つための保護です。

- 電源を入れる途中は、IRS2003 の出力がまだ決まらず、ゲートが浮きます。このときドレインの電圧が急に上がると、MOSFET 内部の容量を通ってゲートが持ち上げられ、MOSFET が勝手にONになることがあります。上下で同時に起きると短絡です。
- 隣の MOSFET の切り替えによるノイズで、ゲートが持ち上がるのも抑えます。

高側を 100kΩ と大きくしているのは、高側がONの間、R_gs_H に流れる電流も C_boot から出るためです。高側を 10ms ONにしたときの、C_boot の電圧低下は次のとおりです (C_boot = 1µF、IC の消費電流 55µA を含む)。

| 高側の R_gs | R_gs に流れる電流 | 10ms での電圧低下 |
|---|---|---|
| なし | 0 | 約 0.6V |
| 100kΩ | 約 0.115mA | 約 1.7V (11.5V → 約 9.8V) |
| 10kΩ | 約 1.15mA | 約 12V (空になる) |

100kΩ なら、10ms の終わりでもゲート電圧は約 9.8V 残り、2SK4017 (4V駆動) のONは保たれます。PWM (約19.5kHz) では1周期が約 51µs と短いので、電圧低下はごくわずかです。

**ブートストラップコンデンサ C_boot (1µF)**

ゲート電荷量を仮に 20nC とすると、1回のONでの電圧低下を 0.5V に抑えるには 40nF 以上が必要です。IC の消費電流と R_gs_H の電流も加わるため、余裕を見て 1µF にします。耐圧 25V 以上のセラミック (X7R) を使います。(ゲート電荷量は未確認の仮定値です。)

**ブートストラップダイオード D_boot (SBM245L)**

耐圧 45V で、バス電圧 12V に対して十分です。順方向電圧が小さいショットキーなので、C_boot をより高い電圧まで充電できます。

**C_vcc (10µF + 0.1µF)**

IRS2003 の電源を安定させます。ICのすぐそばに置きます。

**C_bus (100µF + 0.1µF)**

スイッチングの瞬間に流れる電流を、MOSFET のすぐ近くから供給し、電源電圧の揺れを抑えます。100µF の電解が大きな電荷を、0.1µF のセラミックが速い変化を受け持ちます。

**プルダウン、プルアップ (10kΩ)**

マイコンのリセット中や書き込み中は、ピンがハイインピーダンス (どこにもつながっていない状態) になります。HIN を GND へ、/LIN を +5V へ引いておくと、そのときも全OFF (HIN=0、/LIN=1) になります。

**VCC = 12V**

UVLO の上側しきい値 (標準 8.9V、最大 9.8V) を十分に超えます。VB は D_boot の順方向電圧の分だけ低くなり、約 11.5V です。

## 6. ファームウェア

[`firmware/02-half-bridge/main.c`](../firmware/02-half-bridge/main.c)

| ピン | 機能 | 接続先 |
|---|---|---|
| PA4 (2番ピン、TCA0 WO4) | HIN | IRS2003 の 2番ピン |
| PA5 (3番ピン、TCA0 WO5) | /LIN | IRS2003 の 3番ピン |

PA4 と PA5 は、TCA0 の WO4 と WO5 の既定のピンです ([Microchip: TCA Pin Positions](https://onlinedocs.microchip.com/oxy/GUID-ACE76F82-8072-410B-AFA7-16B2BF7B4CBA-en-US-8/GUID-9E1155F0-F789-41FC-B240-9CAE98BBDC61.html))。WO3〜WO5 は TCA0 の分割モード (8bit×2) でのみ出力されるため、このファームウェアは分割モードを使います。

### 6.1 動作

次の2段階を繰り返します。

1. **静的テスト**: 全OFF (1秒) → 低側のみON (2秒) → 全OFF → 「低側5msON → 全OFF → 高側10msON」を20回 → 全OFF。
   - 高側は長くONにできないため (3.5 節)、短いパルスにしています。各回の最初に低側をONにして、C_boot を充電します。
   - 状態を切り替えるときは、必ず全OFFを挟みます。
2. **PWMテスト**: 約19.5kHz (8bit、256段階)、デューティを10%から90%まで10%刻みで往復 (各1秒)。
   - HIN と /LIN に同じ波形を出すと、4.3 節のとおり相補駆動になります。デッドタイムは IC の内蔵分 (標準520ns) です。
   - デューティは、高側がONの割合です。上限 90% は、C_boot を充電する時間を残すためです。

### 6.2 タイマの設定

クロックは 20MHz に設定しています (既定は 20MHz/6 = 3.33MHz)。20MHz 動作には電源 4.5V 以上が必要なため、ATtiny1604 は 5V で動かします (データシートで要確認)。

分割モードの TCA0 は 8bit なので、20MHz を4分周して周期256にすると、約19.5kHz になります。

分割モードのコンペアレジスタにはバッファがなく、書くとすぐ反映されます。HIN と /LIN を1つずつ書き換える一瞬に、HIN の High が /LIN の High より長くなると、上下が同時にONになる指示が出ます。そのため、デューティを上げるときは /LIN を先に、下げるときは HIN を先に書き換えています。

### 6.3 書き込み

```sh
docker exec avr-builder-dev make -C firmware/02-half-bridge flash PORT=/host-dev/ttyUSB0
```

- `D_boot` は、+12V から VB へ向かうダイオードです (`v` が電流の向き、`-----` の帯が K = カソード)。

- ATtiny1604 の GND (14番ピン) と PA0 (10番ピン、UPDI 用) は、図では省略しています。
